# 课堂与离线开发约定

本课程为项目一“肌电解码与机器人及灵巧手控制”。两组各 6 人，每组约 3 人负责机器人、3 人负责灵巧手；两组使用同版本基础模块。研究重点是把保留的上肢肌电转成更有表达能力、稳定、易使用的控制指令。第一节课先跑通基础链路。

## 1 任务安排

| 阶段 | 机器人方向 | 灵巧手方向 |
| --- | --- | --- |
| 基础起步 | 停止、前进、左转、右转四类 | 停止保持、张开、握合三类 |
| 基础扩展 | 加入后退、左移、右移成为七类 | 五类预设姿态：停止保持、张开、握拳、食指指向、双指伸展 |
| 进阶探索 | 强度映射连续速度/方向，或不同分量混合控制 | 逐指离散控制、连续幅度与低维协同 |
| 期末展示 | 统一吃金币任务，比较完成率与用时 | 展示进阶探索及其实时控制效果，说明精准度、灵活度、稳定性与局限 |

本版提供多分类的采集输入、场景输出、基线分类模型与基础评估。学生先完整运行，再改进信号处理、特征、模型或稳定控制。进阶方法由学生自行扩展。

机器人现有 MuJoCo 行走与平衡策略负责执行速度指令；手部提供模型和预设姿态。课程另有手部重定向基础资源，不代表本 Demo 已集成肌电逐指重定向。

## 2 第一节课最小完成项

1. 教师启动 `start.cmd`，先用模拟设备检查一次完整流程。
2. 首页选择实验线，在“02 采集数据”的“任务方案”中选择本线类别。首次使用建议机器人四类、灵巧手三类。
3. Cometa 轮流使用。每条线先约定“肌肉动作 → 控制类别”，在“采集记录…”保存通道对应位置与动作映射，后续自动复用。
4. 填组别和“人员编号_轮次”，默认采 5 组、每动作 5 秒，每次动作前准备 3 秒。首次保留固定顺序；熟悉后可勾选打乱。
5. 训练默认分类器，查看按完整动作组划分的训练、验证、测试结果。随后用实时信号自由练习。
6. 时间允许再采一轮独立记录，选择“基础评估”回放；或直接使用实时提示评估。
7. 在“数据与模型”导出数据、模型或离线实验包，并保留本次动作映射记录。

第一节课不要求完成七类、五类的全部改进，也不要求实现连续控制。模拟输入能验证流程，但不能说明真实肌电可以分出同样的类别。

## 3 最少需要遵守的数据规则

- 一次采集一个 session；一组动作是一个完整 trial。保持电极位置、通道顺序、受试者和动作映射在同次采集中一致。
- 软件自动保存原始肌电、采样率、通道编号、类别表、提示标签、时间与组别。用“采集记录…”补充操作者代号、佩戴轮次、通道位置和动作映射。采集中做错动作可点“标记本组无效”，原始信号保留，训练和基础回放评估跳过整组；按需补采。
- 提示标签不是实际动作的自动测量。出现动作迟做、疲劳、掉电极等情况，检查记录后补采。
- 新增类别就选择对应新任务并重新采集。不同任务的记录或模型不能混合；不能给四类数据补写标签当七类数据。
- 原始 `.emg` 应保留。模型包只是计算结果，不能替代训练数据。
- 基础课不强制增加强度标定、关节传感器或复杂同步表单；只有选择连续控制课题时，才设计相应标定和标签方案。

## 4 练习与基础评估

实时推理与文件回放使用同一 MuJoCo 场景。回放将原始肌电重新送入模型，场景由预测指令驱动；标签只负责提示和计分。采集时的场景则是动作示范，用于引导采集。

**自由练习：** 机器人练习前进、停止、转向，七类增加后退与侧移；灵巧手练习姿态切换与停止保持。此模式不计比赛分数。

**实时基础评估：** 每类两次，随机顺序，每次准备与动作各 3 秒。输出报告记录正确率、混淆矩阵、停止误触发、首次正确响应、指令切换次数及连续正确跨度。提示不会直接控制机器人或手。

**回放基础评估：** 将预测与原标签比较。模型关联数据标注“自查”；另采的未使用记录才用于检查新一轮表现。按 trial 留出的原测试集可用于训练阶段评估，但回放同一记录不是一次新的独立现场试验。

评估文件在 `data/<组别>/evaluations/`，包含 HTML 与 JSON。提前结束保留未完成标记。从“数据与模型 → 评估记录”打开或导出历史结果。有效窗口数不是独立动作次数；首次正确时间包含人的反应与整条处理链路，不能当作机械手到位时间。

新增“金币任务”模式，支持固定种子、收集进度、限时与统一排名规则；基础评估和自由练习仍各自独立。固定录制的回放信号无法根据场景位置主动调整，不能代替实时闭环控制能力的考核。

## 5 一台 Cometa 与课后开发

课堂集中采集并检查质量；离线用 `.emg` 完成训练、调试和回放，减少设备等待。需要新动作、强度标定或重新佩戴测试时，再安排补采。

“数据与模型”页按组别、日期、设备、目标与名称筛选。导出离线实验包会创建独立目录，包含所选数据、模型、本机能找到的关联训练数据、校验清单与操作说明。找不到的关联记录会列明。另保留教师发放的学生离线包，其中包含源码、Python、依赖、3D 资源与模拟示例。换电脑后先运行 install.cmd，再导入自己的实验包（无学生包时从 GitHub 克隆或下载 ZIP 后联网运行 install.cmd 亦可）。

离线实验包结构：

```text
EMG_离线实验包_日期_编号/
├─ recordings/
├─ models/
├─ manifest.json
├─ 阅读说明.txt
└─ 课堂与离线开发约定.md
```

## 6 进阶与期末预留

机器人金币任务已接入统一 MuJoCo 运控；默认 6 枚、120 秒、3 个共同种子，先比较总完成率，再比较计入未完成惩罚的总用时。所有模型同一榜单；固定分类使用基础速度档，通过教师验收的连续/混合控制可使用进阶速度档，两档加速度和计时规则相同。正式种子和赛程由教师冻结，详见帮助中的“金币任务与比赛规则”。

灵巧手采用进阶成果展示，鼓励逐指、幅度和协同等探索，不预先承诺一个目前尚未验证的统一真实抓握任务。每组说明尝试了什么、如何验证、哪些情形有效或失败；是否接真实手根据后续设备验证决定。

期末由学生携改进项目到实验室采集和训练，使用统一评定程序。类别编号、连续速度向量、范围和停止规则见 `COMPETITION.md`；通用连续模型导入界面仍需学生自行扩展。不要给旧任务编号改变含义。

研究对照使用相同测试记录、速度范围及评估设置，报告成功和失败案例。比赛的进阶速度奖励与算法本身的改进应分开解释。基础三类手部的“握合一会儿再停止”是离散指令保持，不等于解码肌电强度。

手部新姿态只完成仿真与软件验证，机器人七类和手部五类暂不启用真实输出。基础三类/四类的真机连接入口继续保留，由教师按既有设备流程使用。
