# 手部五类姿态：来源与切换

本版使用 BrainCo 官方 ROS2 Gazebo 示例中的四个目标姿态，加入“停止保持”组成五类任务。它们是厂商公开的仿真示例，不等同于已经在本机硬件上验证的固件动作。

- 角度来源：[brainco_hand_ros2 / brainco_gazebo README](https://github.com/BrainCoTech/brainco_hand_ros2/blob/master/brainco_gazebo/README.md)
- 本地模型来源：[revo2_description](https://github.com/BrainCoTech/revo2_description)，具体资源版本见 `assets/revo2` 的来源清单。
- 实现：`emg_lab/hand/poses.py`。官方示例顺序中掌指关节在前，本地代码交换前两个角度，与 URDF 主动关节顺序对齐。

## 1 类别和角度

下表单位为弧度。顺序是拇指 proximal、拇指 metacarpal、食指、中指、无名指、小指。

| class_id | 类别 | 六关节目标 |
| --- | --- | --- |
| 0 | 停止保持 | 保持当前插值位置，不跳到固定姿态 |
| 1 | 张开 open | 0.1, 0, 0, 0, 0, 0 |
| 2 | 握拳 fist | 0.8, 0.3, 1.2, 1.2, 1.2, 1.2 |
| 3 | 食指指向 point | 0.8, 0.3, 0, 1.2, 1.2, 1.2 |
| 4 | 双指伸展 victory | 0.8, 0.3, 0, 0, 1.2, 1.2 |

五类中的握拳是到达目标姿态；原基础三类中的握合是四指继续合拢，两者任务标识和模型分开。预设姿态分类不等于逐指独立解码。

## 2 切换规则

一个控制器维护当前角度和目标序列。切换到新的非停止姿态时，依次伸开四指、移动拇指、再弯曲相应手指。每段按最大关节变化量同步插值，最高 0.9 rad/s。

新指令从当前角度接管，并替换未完成序列。重复相同指令不重新执行；停止取消剩余动作并保持，恢复指令从停住的位置开始。分类阶段原有置信度阈值与连续判定仍有效，低置信度回到停止保持。

## 3 已验证和待验证

已验证六主动关节的 URDF 范围、mimic 运动、四个目标间全部有向切换、途中停止/改目标、重复指令、3D 渲染和模拟信号推理链路。

当前模型用于运动学展示，网格接触检测关闭。这里的平滑阶段顺序解决软件指令相互覆盖和跳变问题，不构成真实手的防碰撞、抓握力或负载验证。新增五类只开放仿真；真实手仍使用原基础三类入口。开展新增真机动作前需教师单独验证硬件映射、行程与机械干涉。
