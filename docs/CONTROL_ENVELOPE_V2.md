# 运控范围实验与规则 v2

2026-10-25 · 教师试运行版。实验对象为本 Demo 的 G1 / MuJoCo / NVIDIA Walk–Balance 策略，未更换权重、关节 PD、物理步长或金币场景。

## 推荐定版

| 控制额度 | 固定分类 / 基础档 | 已验收连续或混合 / 进阶档 |
|---|---:|---:|
| 前进 | 0.6 m/s | 上限 0.8 m/s |
| 后退 | 0.4 m/s | 上限 0.6 m/s |
| 左右侧移 | 0.4 m/s | 上限 0.6 m/s |
| 左右转向 | 1.0 rad/s | 上限 1.2 rad/s |
| 合成平移上限 | 0.6 m/s | 0.8 m/s |

固定分类执行固定幅度的单个动作；连续/混合控制可在对应范围内调节幅度和比例。先逐轴限幅，再限制平移向量长度，转向独立。两档都使用 1.5 m/s² 平移、2.5 rad/s² 转向指令变化率。直行方向补偿最多 ±0.15 rad/s，原策略小指令零区保留。上述单位描述目标指令，实际速度会有跟踪误差。

奖励是**更高速度额度**，没有时间折扣或另加金币。所有模型同榜，先比较总收集数，再比较总计分用时；未完成局记满限时。进阶资格由教师核验实时肌电幅度或比例控制能力，并绑定组别、模型哈希和共同程序基准。详细验收要求见《机器人金币任务说明》。

## 为什么这样选

旧侧移目标 0.25 m/s 的实际侧向均速约 0.18 m/s，操作显得慢。基础档提高到 0.4 后，实测约 0.28–0.30 m/s；进阶档 0.6 时约 0.44–0.45 m/s。左右略有差别来自现有运控策略，没有用不同的左右指令补偿，以便课程规则清楚。

前进 0.6 与 0.8 的实际均速约 0.55 与 0.75 m/s。探索时前进 1.0 仍可站稳，但停止后的水平漂移约 0.68 m，超过本轮 0.55 m 筛选线；0.8 约 0.47 m，因此暂不放大到 1.0。1.6 的三个初始化中有两个触发大倾斜/高度失败，已保留这些失败结果。

转向停止后也有余转：基础档 1.0 的本轮单轴试验最大约 14.5°，进阶 1.2 约 17.8°。候选试验中更大的左转 1.6、2.0 可到约 31°、48°余转。因此转向只增加 20%，不追求策略仍能站稳时的最大角速度。进阶档需要操作者利用幅度调节，在接近目标时提前减速。

## 实验方法与边界

机器人初始偏航随机，29 个关节加入标准差 0.004 rad 的小扰动；先停止站稳 3 秒。策略 50 Hz，物理 200 Hz；没有用直接改位置实现行走。范围探索脚本在仿真测试内部绕过应用限幅，但保留变化率限制、方向补偿和原物理策略；课堂程序不使用该绕过方法。

筛选指标：无跌倒/数值失败，骨盆最低高度 ≥0.55 m、最大倾斜 ≤35°；持续至少 3 秒的停止段在 2.5 秒内达到稳定窗口，最大水平漂移 ≤0.55 m。稳定窗口为连续 0.5 秒的平均水平速度长度 <0.07 m/s、平均转速绝对值 <0.10 rad/s。这个指标衡量平均停稳，不表示每个瞬时速度都为零；余转角另行记录用于取值判断，不作为统一硬阈值。

最终扰动条件：默认接触摩擦、所有接触几何的滑动摩擦系数乘 0.7 / 1.3，以及站稳后初始水平速度 ±0.12 m/s、角速度 ±0.15 rad/s 扰动。不是任意地形、任意信号的安全保证，也不适用于真机直接限速。

| 阶段 | 用例 | 稳定通过 | 停车指标通过 | 作用 |
|---|---:|---:|---:|---|
| 单轴幅度探索 | 123 | 121 | 103 | 包含过大速度，保留失败样本 |
| 候选范围比较 | 204 | 204 | 203 | 比较椭球/独立轴、快速切换、转向余转 |

最终进阶范围最大倾斜 12.69°、最低高度 0.720 m；基础固定档最大倾斜 10.90°、最低高度 0.731 m。候选独立轴组合有一例停车漂移约 0.554 m，最终加入合成平移上限 0.8 m/s 后的 194 个验证全部通过。

## 留存与复现

原始 JSON 与汇总在 `verification/control_envelope_v2/`，代码在 `scripts/control_study/`；`artifacts_sha256.json` 给出留存文件哈希。单轴和候选原始文件里的旧 `stop_ok` 有已知统计口径问题：过短停止段也计入失败，以及早停时空列表误判通过。原始文件不改写；本报告和 `summary.json` 按至少 3 秒停止段重算，并将运动失败记为不通过。候选阶段的摩擦扰动只改地面，低摩擦可能被脚部接触系数抵消；最终 194 + 84 个试验已修正为同时调整全部接触几何，不以候选阶段宣称低摩擦通过。
