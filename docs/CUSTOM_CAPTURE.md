# 自定义动作采集

机器人实验的“02 采集数据”增加“自定义动作采集（不关联机器人）”。课程预设四类/七类以及灵巧手原流程仍保留，设备收数、滤波、采样时钟、原始信号编码不变。

## 操作

1. 在设备连接页选择实际设备和通道；没有硬件时可选模拟设备检查软件流程。
2. 在采集页切换到自定义方式，填写组别与本次数据名称。每次开始后配置冻结，结束后才能编辑。
3. “动作条件”每行表示一个动作与力道条件，支持 1–64 行。可以新增、复制和删除；重复动作名称允许存在，各行使用独立的稳定编号。双击单元格编辑。没有强制的“停止”类别，需要静息时自行增加。
4. 填写动作名称、执行部位、力道/目标、保存名称和备注。力道是操作者的实验条件，不是测得的力值。保存名称留空时沿用动作名称。
5. 在“佩戴与通道记录”填写操作者代号、佩戴批次/姿态、本轮备注，以及每个实际通道的肌肉位置和备注。通道数来自设备配置，不能通过备注改变；更改通道需重新连接设备。连接、加载方案和开始采集时都会核对/刷新通道，保留相同通道编号的注释。
6. 选择“勾选动作轮采”或“仅当前行补采”。前者每轮遍历全部勾选条件；后者只采当前高亮行，忽略其他勾选。两者均可设置重复次数、1–10 秒动作时长以及随机顺序；沿用原有每动作准备 3 秒、额外休息 0 秒的时序。
7. “保存方案/加载方案”使用 JSON，保留全部条件及稳定编号、有效选择、通道注释、操作者记录、重复次数、时长和随机设置。换人或重新佩戴后核对记录。
8. 开始后显示文字提示、倒计时、部位/力道/备注和波形；不启动 3D，也不发送机器人动作。提前结束仍保存原始信号，可标记当前轮无效，结束后选单个动作补采。

## 文件与对应关系

每次采集在 `data/<组别>/recordings/` 下生成同名的一对文件：

```text
日期时间_本次数据名称_唯一编号.emg
日期时间_本次数据名称_唯一编号.index.csv
```

`.emg` 仍是原有的三成员容器：`emg.bin`、`labels.csv`、`meta.json`。原始信号完整保留，准备阶段也保存。原 `labels.csv` 字段与二进制布局不变。

新增任务类型 `EMG_CUSTOM_CAPTURE_V1`，标识 `capture_only=true`。`meta.json.capture_plan` 保存冻结的条件表、被选条件的稳定 ID 与注释。`classes` 和标签 `class_name` 使用本次选中条件的稳定 ID；`class_id` 是本文件中局部的零起始编号，**不能跨文件直接当成相同动作或机器人命令**。单动作补采时局部编号为 0，稳定 ID 仍与原方案对应。新旧的机器人/手部任务 ID 不变。

索引 CSV 使用带 BOM 的 UTF-8，便于 Excel 打开。每行是一个实际收到数据的动作片段，包含：

- 原始文件名、`record_id`、本次数据名称。
- `condition_id`、动作、执行部位、力道、保存名称与备注。
- `segment_name`：`<保存名称>_R<轮次>_S<段序号>`，用于片段命名，不另拆原始信号文件。
- 半开区间 `[start_sample,end_sample)` 与相对秒数。按照原始记录的采样率定位，不使用屏幕刷新时间。
- 操作者、佩戴记录、实际通道数量及各通道注释。
- `complete_segment`、`complete_trial`、`valid` 和无效原因。`valid` 仅表示没有人工标记无效，不能替代完整性或信号质量判断。

提前结束时，未完整的动作不加入原 `labels.csv`；如果已经收到部分动作数据，CSV 会标出该片段实际结束位置，并标记 `complete_segment=false`。还未开始的动作不生成索引行。

**`.emg` 是权威记录，CSV 是派生索引。** 导入、导出和重新导入同一记录时会重建索引；只带走 `.emg` 也不会丢失动作注释。导出的离线实验包保留 `.emg` 及派生索引，导入时以受校验的 `.emg` 重建。不要通过改 CSV 给原始数据重新贴标签。

## 使用边界与兼容

自定义数据可以在“数据与模型”查看、筛选、导入、导出。现阶段不加入固定四/七类训练或推理，不映射到机器人动作。后台同样拒绝直接训练这类数据，避免把自定义第 0 类误解释成停止。后续分析应使用稳定 ID 和方案说明建立新的分析标签/映射，保留原记录。

旧数据和原有课程流程继续可用；新增自定义类型需要本分支的读取器，未升级的老师原版会拒绝这个未知任务类型。旧模型、预处理、划分和比赛规则没有修改，比赛基准也没有重新生成。

模拟信号、自动化测试和离屏界面渲染只证明软件流程，不能证明真实肌电识别质量或设备验收结果。
